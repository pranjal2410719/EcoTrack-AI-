# EcoTrack AI — Feature List

- Hero section with tagline and CTA
- Features grid (4 cards)
- How It Works (3 steps)
- Call-to-action button

### F2: Authentication ✅
- Clerk-powered sign-in / sign-up

- User session management

### F3: Carbon Assessment Form ✅

- Electricity: Monthly bill amount
- Diet: Vegan / Vegetarian / Non-Vegetarian

- Shopping: Monthly purchases

### F4: Carbon Calculator ✅
- Server-side calculation
- Score breakdown by category

### F5: AI Analysis ✅
- Gemini API integration
- Personalized recommendations
- Weekly sustainability plan
- Reduction opportunities

### F6: Dashboard ✅
- Carbon score card with level indicator
- Emission breakdown pie chart (Recharts)
- AI recommendations cards
- Progress comparison (faked historical data)

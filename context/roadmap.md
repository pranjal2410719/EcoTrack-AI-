# Product Roadmap

## Current Status (MVP)

✅ User authentication (Supabase Auth)
✅ Carbon footprint calculator
✅ AI-powered recommendations (Gemini)
✅ Interactive dashboard with charts
✅ Progress tracking
✅ Responsive design
✅ Automated testing (Jest)
✅ ESLint + Prettier
✅ Controller-Service architecture

## Near-Term (Next 30 Days)

- **Goal Setting**: Users set monthly carbon reduction targets with notifications
- **Leaderboard**: Community rankings with opt-in anonymity
- **Export Reports**: Generate PDF reports of carbon footprint history
- **Notification System**: Weekly email summaries and achievement alerts

## Medium-Term (60 Days)

- **Mobile App**: React Native companion app
- **Social Features**: Share achievements, group challenges
- **Carbon Offset Integration**: Donate to verified offset projects via API
- **Multi-language Support**: i18n for regional languages

## Long-Term Vision

- **API Marketplace**: Open API for third-party integrations
- **AI Coach Upgrade**: Conversational AI assistant for daily tips
- **IoT Integration**: Connect smart home devices for automatic tracking
- **Enterprise**: Team/org accounts with admin dashboard
- **Carbon Credit Trading**: Blockchain-verified credit marketplace
